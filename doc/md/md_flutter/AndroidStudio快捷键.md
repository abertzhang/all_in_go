## AndroidStudio快捷键

- 热重载 ctrl + \ ,ctrl+s 保存后自动重载
- 注释//  ctrl + /
- 删除一行 ctrl + x 
- Generate  Alt + Insert
- 重写方法 Ctrl + o
- 接口implements方法 Ctrl + i
- 展开代码块ctrl+shift+'+'
- 收缩代码块ctrl+shift+'-'
- 多行编辑alt+shift+insert



- 复制一行 ctrl + d
- git commit命令 ctrl + k
- 设置面板 ctrl+alt+s
- 保存所有 ctrl+s
- 重命名 shift+F6
- Run main命令 shift+F10
- debug main 命令 shift+F9
- Project面板 alt+1
- structure面板 alt+7
- 版本控制面板 alt+9
- terminal面板 alt+F2
- git创建分支 ctrl+shift+`
- 主窗口 ctrl+shift+F12
- 光标跳到定义的地方 F4
- 定义或使用的地方 ctrl+b
- 抽离成Widget  ctrl+alt+w
- 抽离成方法 ctrl+alt+m
