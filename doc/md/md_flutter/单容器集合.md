### 类Contain构造

```dart
Key key,            			 //
Widget child 					//可放单个子组件widget
AlignmentGeometry alignment,    //设置子组件的对齐方式
EdgeInsetsGeometry padding,     //设置容器的内边距
Color color,     		        //容器的颜色
Decoration decoration,			//容器的修饰属性也可设背景颜色,但不能与color同用! 用类BoxDecoration来修饰
Decoration foregroundDecoration,  //容器前景修饰
double width,  					//容器的宽度
double height, 					 //容器的高度度
BoxConstraints constraints,  	//设置子组件的约束
EdgeInsetsGeometry margin, 		 //设置容器的外边距
Matrix4 transform,  		//容器的形状变化属性,旋转和缩放等
```
