### 拉取仓库代码

```
git clone git://github.com/schacon/grit.git 
```



### 查看仓库地址

```
git remote show//先查看远程名称
git remote show origin //显示远程库origin里的资源名称
```

### 添加远程地址

```
git remote add origin git@192.168.1.119:ndshow
```



### git推代码

```

git push origin master //将文件给推到服务器上
```
