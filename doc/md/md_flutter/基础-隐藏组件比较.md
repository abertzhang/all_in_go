### 类Offstage

```
Offstage(
  offstage: true,
  child: Text("补测"),
  )
```

这种方式性能其次,如果child是动画需要手动关闭动画,否则还会运行

### 类Visibility

这种方式性能最好,可以多重方式控制chiild

```
Visibility(
  visible: true,
  maintainAnimation: true,
  maintainSize: true,
  maintainState: true,
  child: Text("补测"),
)
```

如果visible是true代表显示，否则隐藏。默认隐藏是不占据空间的，如果想保留空间大小，需要添加几个属性,其中maintainSize就是保持大小不变，但是单独设置这一个不行，会报错，maintainAnimation和maintainState也需要同时设置。

### 类Opactiy

通过透明度实现是否可见,比较其他方式性能最差

### 条件判断if隐藏组件

```dart
if(isShow) Text('显示这个Widget')
```

这种方式会影响三棵树,条件变化时被重新渲染renderObject
