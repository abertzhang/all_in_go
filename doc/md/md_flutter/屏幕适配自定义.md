### 自定义适配

##### 应用场景

屏幕大小以2倍图720-1280px或360-640dp

##### 代码示例

```
//全局变量,设计稿是dp用MediaQuery,设计稿px用windows
double w,h;
//获取手机的dp单位,模拟手机的和设计手机必须一致,单位必须一致,该模拟机是360*640单位dp
    if (w == null) {
      w = MediaQuery.of(context).size.width / 360;
      h = MediaQuery.of(context).size.height /640;
    }
//如果是px则用window方法,是io库里的,这种方式不太准,因为flutter是height和width是对应dp
 w = window.physicalSize.width/720;//window的单位是px,设计2倍图720*1280px
 h = window.physicalSize.width/1280;//window的单位是px,设计2倍图720*1280px
```
